# Register: Smart Attendance Tracker

> A personal college attendance management and analytics web app for tracking daily attendance, monitoring subject-wise performance, and planning attendance safely around a 75% target.

🔗 **Live Demo:** [Register — Smart Attendance](https://lodger.ai.studio)

---

## 📌 About the Project

**Register** is a personal web application I built to manage and analyze my college attendance.

Instead of manually calculating attendance after every class, I use Register to record my daily attendance against my timetable. The application keeps track of attended, absent, and cancelled classes and uses the recorded data to provide an overview of my attendance status.

The app is designed around a **75% minimum attendance target** and helps me understand which subjects are safe, which require more attendance, and how many classes I can potentially skip while staying above the target.

---

## ✨ Features

### 📅 Daily Attendance Tracking
- Record attendance for each class every day.
- Mark classes as:
  - ✅ Present
  - ❌ Absent
  - ⊖ Cancelled
  - 🔄 Substitute
  - Any Other Case (Specify)
- Navigate between previous and future dates.
- Maintain a history of attendance records.

### 🗓️ Timetable Management
- Store my regular college timetable from **Monday to Saturday**.
- Keep track of subjects and their scheduled class timings.
- Automatically display the relevant classes for each day.

### 📊 Attendance Analytics
- View overall attendance percentage.
- Track total classes and total attended classes.
- Monitor attendance separately for each subject.
- Visualize attendance through charts and progress indicators.
- Set and monitor a **75% attendance threshold**.

### 🛡️ Attendance Safety Status
The application evaluates my attendance against the target threshold and provides a quick indication of my current attendance safety.

It helps identify:
- Subjects comfortably above the target.
- Subjects close to the threshold.
- Subjects where additional attendance is required.

### 🔮 Skip Planning & Prediction
Based on the attendance data recorded in the application, Register helps estimate:

- How many classes can potentially be skipped.
- Which subjects have room for skipping.
- Which subjects require attending more classes before reaching a safer level.
- The effect of future attendance decisions on the overall percentage.

### 📈 Subject-wise Tracking
Each subject can be monitored independently so that attendance problems in one subject don't get hidden by a high overall percentage.

### 📜 Attendance History
Maintain a historical record of attendance so previous entries can be reviewed, edited, or analyzed.

---

## 🎯 Problem It Solves

College attendance can become difficult to manage when different subjects have different attendance percentages and class schedules.

A simple attendance percentage does not always answer practical questions such as:

> "How many more classes do I need to attend?"

> "Can I safely miss the next class?"

> "Which subject needs more attention?"

> "What happens to my percentage if I miss a few classes?"

Register was built to make these calculations easier by combining **daily attendance logging, timetable information, analytics, and predictive planning** in one place.
